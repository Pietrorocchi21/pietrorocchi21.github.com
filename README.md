# PR. — Nebula Glass Portfolio

Portfolio personale di Pietro Rocchi. React + Vite + TypeScript + GSAP.

## Funzionalità
- Nebulosa interattiva con Canvas 2D, stelle e parallax sul puntatore
- Layout continuo, senza scroll-snap o sezioni a schermo intero
- Pannelli glassmorphism e animazioni di ingresso GSAP
- Lingue italiano e inglese
- Link a repository GitHub reali, stati di sviluppo dichiarati
- Supporto reduced-motion e layout mobile

## Sviluppo
`npm install` poi `npm run dev`.

## Pubblicazione
GitHub Pages configurato per `https://pietrorocchi21.github.io/` con `base: '/'`.
Caricare i file nella radice della repository `Pietrorocchi21/pietrorocchi21.github.com` e mantenere `.github/workflows/deploy.yml`.
In GitHub Settings > Pages, Source: GitHub Actions.

Nota: la descrizione dei progetti è stata basata sui README GitHub; verificare prima di presentare nuove funzionalità come completate.
